Spiffing for Openfire

Server clearance enforcement for XEP-0258 security labels, using Spiffing Java. Requires Openfire 5.0.0 or later and Java 22 or later.

Open Server Settings → Spiffing security labels to configure an Open XML SPIF policy, server clearance, and default message label. Ordinary inbound messages are blocked until valid configuration is saved.

Unlabelled messages receive the configured default. Labelled messages must pass both policy validation and the server clearance check. ESS, NATO XML, and Spiffy XML are supported. Configuration is saved in OPENFIRE_HOME/conf/spiffing.xml.

This first increment enforces the server clearance. It does not implement per-user or per-room clearances, label catalogues, history filtering, cross-policy translation, or cluster-wide configuration distribution.
